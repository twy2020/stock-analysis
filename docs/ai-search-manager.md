# AI 搜索引擎管理器

管理员入口：SaaS `/admin` 的「AI 搜索引擎」。聊天联网开关和管理员功能开放仍是调用前提。

## 调度

- 按管理员优先级选择已启用、已配置的供应商；失败或没有可引用来源时切换备用。
- 本地 ai-search-mcp 每次并发最多三个引擎、三个查询，进程共享四个并发槽。
- 每个供应商超时 5–25 秒，总搜索预算 40 秒；失败冷却 60 秒。状态在当前单进程后台保存，重启清空。
- 管理员可选择本地引擎；空列表按代理配置自动选择。远程 MCP 的 site/freshness 不受支持时返回明确提示。
- Dhole 单独负责网页读取，搜索摘要不等同已读取正文。

## 供应商

| 供应商 | 接入 | 当前状态 |
| --- | --- | --- |
| ai-search-mcp | 已安装的固定 stdio 命令 | 默认启用；DuckDuckGo 经配置代理实测可用 |
| 百度千帆 | 固定官方 Streamable HTTP 端点 | 需独立 API Key；端点未认证请求返回 401，真实搜索待配置凭据验证 |
| 知乎 | 固定官方 SSE 端点 | 需独立 API Key、平台权限；真实搜索待配置凭据验证 |
| DeepSeek web_search | Responses API 能力记录 | 当前官方文档标注内置 web_search 被忽略，禁止启用 |

依据：https://api-docs.deepseek.com/guides/responses_api 。正式模型仍使用管理员选择的 DeepSeek 官方 `deepseek-flash`；不把模型回答当作搜索结果。

## 凭据和测试

供应商设置加密保存至独立 `stock.search_manager` SystemSetting；查询设置不回显密钥。留空保留旧密钥，清除操作需保存。

测试已保存配置会发起一次真实搜索，发现 MCP 工具、检查查询 schema，并要求真实来源 URL。多个搜索工具时管理员需指定工具名称；不猜测未知必填参数。失败只返回安全错误码，不返回供应商异常文本。

统一来源去重、截断摘要、保留供应商标记。每次搜索最多八条来源。搜索端点固定，模型不能选择服务器地址、命令、凭据或代理。

千帆/知乎默认关闭。文章中的免费额度未确认，以账户控制台最新权益和计费为准。
