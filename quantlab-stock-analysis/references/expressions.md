# 指标表达式语言

白板、买点筛查、算法回测、数理分析用的是同一套表达式。服务端实现在 `<项目>/expr.py`，前端实现在 `<项目>/static/whiteboard.js`，两边语义必须一致——改一边就必须同步另一边，并做逐元素比对。

## 字段

| 写法 | 含义 | 单位 |
| --- | --- | --- |
| `OPEN` / `O` / `开盘` / `开盘价` | 开盘价 | 元 |
| `HIGH` / `H` / `最高` / `最高价` | 最高价 | 元 |
| `LOW` / `L` / `最低` / `最低价` | 最低价 | 元 |
| `CLOSE` / `C` / `收盘` / `收盘价` | 收盘价 | 元 |
| `VOLUME` / `V` / `成交量` | 成交量 | **手**（1 手 = 100 股） |
| `AMOUNT` / `A` / `成交额` | 成交额 | 元 |

数据**未复权**，跨除权日的价格指标会有台阶。

## 运算符

`+ - * / ^`（幂）、括号、比较 `>` `<` `>=` `<=` `=`（也可写 `==`）`!=`（也可写 `<>`）、逻辑 `AND`（`&&`）`OR`（`||`）`NOT`。

比较和逻辑遇到缺失值一律按**不成立**处理；谓词类函数（`CROSS`、`EVERY`、`ISMAX`…）返回 1/0。

## 函数

周期参数必须是 1~1000 的整数，非整数会直接报错。

| 函数 | 语义 |
| --- | --- |
| `MA(s,n)` | n 根简单移动平均。窗口内有缺失 → 结果缺失 |
| `EMA(s,n)` | 指数移动平均，α=2/(n+1)，首值取第一个有效值 |
| `SUM(s,n)` | n 根求和 |
| `HHV(s,n)` / `LLV(s,n)` | n 根内最高 / 最低值（含当前根） |
| `STD(s,n)` | n 根**总体**标准差（除以 n，不是 n-1） |
| `REF(s,n)` | n 根前的值（`REF(CLOSE,1)` = 昨收） |
| `PCTCHANGE(s,n)` | n 根累计涨跌幅，**单位是 %**：`(s[i]-s[i-n])/s[i-n]*100` |
| `RSI(s,n)` | Wilder 平滑的 RSI：前 n 根用简单平均做种子，之后 `avg=(avg*(n-1)+x)/n`；涨跌都为 0 时取 50 |
| `COUNT(cond,n)` | 最近 n 根里满足（非 0）的根数 |
| `EVERY(cond,n)` | 最近 n 根是否**全部**满足 → 1/0（表达"连续 n 天"） |
| `CROSS(a,b)` | 上穿：`a[i]>b[i] 且 a[i-1]<=b[i-1]` |
| `CROSSDOWN(a,b)` | 下穿：`a[i]<b[i] 且 a[i-1]>=b[i-1]` |
| `ISMAX(s,n)` / `ISMIN(s,n)` | 当前值是否 ≥ / ≤ 前 n-1 根（**允许相等**，即"平了也算区间最高/最低"） |
| `NEWHIGH(s,n)` / `NEWLOW(s,n)` | 当前值是否**严格** > / < 前 n-1 根（真突破，不含相等） |
| `PEAK(s,n,k)` / `TROUGH(s,n,k)` | k 根前那一根是 `[peak-n+1, peak+k]` 区间内的最大 / 最小值（滞后 k 根才确认） |
| `MID(a,b)` | a 命中后、下一次 b 命中前，**中间那一根**返回 1 |
| `INSIDE(a,b)` | a 命中后、下一次 b 命中前的**每一根**返回 1（不含两端） |
| `ABS(s)` | 绝对值 |
| `MAX(a,b)` / `MIN(a,b)` | 逐根取大 / 取小（不是区间极值，区间极值用 `HHV/LLV`） |
| `IF(c,a,b)` | c 非 0 且非缺失时取 a，否则取 b |

`MID` / `INSIDE` 需要知道"下一次 b 什么时候出现"，**用到了未来信息**，拿来回测会偏乐观；做研究可以，做回测要清楚这一点。

## 常用条件 → 表达式

系统 UI 里的图形化条件，最终都会编译成右侧的表达式，可以直接拿来用：

| 中文条件 | 表达式 |
| --- | --- |
| 连续上涨 3 天 | `EVERY(CLOSE>REF(CLOSE,1),3)` |
| 连续下跌 3 天 | `EVERY(CLOSE<REF(CLOSE,1),3)` |
| 连续涨停 2 天（近似） | `EVERY(PCTCHANGE(CLOSE,1)>=9.8,2)` |
| 3 天累计涨 8% | `PCTCHANGE(CLOSE,3)>=8` |
| 3 天累计跌 8% | `PCTCHANGE(CLOSE,3)<=-8` |
| 均线金叉 / 死叉 | `CROSS(MA(CLOSE,5),MA(CLOSE,20))` / `CROSSDOWN(...)` |
| 放量 | `VOLUME>MA(VOLUME,20)` |
| 成交量区间极大值 | `ISMAX(VOLUME,20)` |
| 突破 20 日新高 | `NEWHIGH(HIGH,20)` |
| 布林上轨 / 中轨 / 下轨 | `MA(CLOSE,20)+2*STD(CLOSE,20)` / `MA(CLOSE,20)` / `MA(CLOSE,20)-2*STD(CLOSE,20)` |
| 布林位置 %B | `(CLOSE-MA(CLOSE,20)+2*STD(CLOSE,20))/(4*STD(CLOSE,20))` |
| 布林带宽 % | `4*STD(CLOSE,20)/MA(CLOSE,20)*100` |
| RSI 等于 30（带容差） | `ABS(RSI(CLOSE,14)-30)<=0.5` |
| 最高价的三日均线 | `MA(HIGH,3)` |
| 每日最高 − 最低 | `HIGH-LOW` |
| 振幅 % | `(HIGH-LOW)/CLOSE*100` |
| 30 日布林下轨上穿 3 日收盘 EMA | `CROSS(MA(CLOSE,30)-2*STD(CLOSE,30),EMA(CLOSE,3))` |

注意 UI 里的"等于"是**带容差**的：选数值作为比较对象时，`=` 会被编译成 `ABS(左-右)<=容差`（默认容差 0.5）。手写 `=` 则是浮点近似相等（相对容差 1e-9），对 RSI 这类连续值几乎命中不了，所以要写 `ABS(...)<=0.5` 这种形式。

## 量纲自查

写交叉或比较之前，先确认两边量纲一致：价格（元）、比率（%）、成交量（手）、成交额（元）、RSI（0~100）不能随便互相比较。跨量纲的常见做法是先归一化，例如 `CLOSE/MA(CLOSE,20)*100-100`（距均线的百分比）。
