# 事件窗口统计（数理分析）

引擎：`<项目>/feature.py`。回答的问题是「这个事件出现之后，通常怎么走」，而不是「这个策略能赚多少」。它是回测之前的过滤器：**没有统计信息量的信号，回测出来的收益多半是噪声拟合。**

## 方法

1. 用表达式扫出所有**事件 K 线**：表达式结果非 0 的每一根（且前面留够 60 根 `MIN_WARMUP` 预热、后面留够 `after` 根观察）。
2. 每根事件 K 线打包成一条记录：事件前后涨跌幅、事件后窗口内的最大涨/跌幅、事件当根的量比 / 布林位置 %B / RSI14 / 布林带宽，以及**事件后第 1/2/3/5/10 个交易日的收益率**（相对事件收盘，单位 %）。
3. 按「相对事件的天数」把 14 个特征算成均值曲线（`profile`），得到事件前后的行为画像。
4. 把 `forward` 收益率汇成分布（`dist`）：涨/跌/持平概率、均值、中位数、标准差、5/25/75/95 分位、11 档直方图。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `condition` | 必填 | 事件定义，一条表达式 |
| `before` | 5 | 事件前观察几根 |
| `after` | 10 | 事件后观察几根，同时决定 `after_pct` 的口径 |
| `periods` | `[1,2,3,5,10]` | 要统计事件后第几个交易日的收益（1~60） |
| `sample` | 300 | 随机扫描多少只股票（固定种子 2026，同参数可复现）。300 只 ≈ 3000 个事件，耗时约 10 秒 |
| `codes` | 无 | 指定股票池，给了就不抽样 |
| `limit` | 1400 | 每只股票取最近多少根 |

`MAX_EVENTS = 4000`：事件超过 4000 会随机抽样后再统计分布，所以 `n=4000` 表示"实际事件更多，这是抽样后的"。

## 特征面板（14 个）

事件窗口里每个相对日都会算：涨跌幅%、振幅%、实体%、量比（量/5 日均量）、收盘距 MA5/MA20/MA60 的 %、RSI14、布林位置 %B、布林带宽 %、距 20 日高点 %、距 20 日低点 %、5 日累计 %、成交量/20 日均量。

用法是**对比**：看事件前几根这些值怎么爬升、事件当根有什么特征、事件后又怎么回归。这张表也适合直接丢给大模型做特征识别。

## 判读规则

- **先看 n**：`n < 30` 基本没有统计意义；几百以上才值得讨论。注意 `n` 不是独立样本数——同一只股票连续两天命中就算两个事件，**事件重叠会让 n 虚高、显著性被高估**。
- **要有基准**：某信号"后 3 日上涨概率 55%"到底算不算高，得和同期全市场对照。A 股长期上涨概率本身就在 50% 附近波动，55% 和 52% 的差距是否稳定，要看条件分布（分位、直方图），不要只看一个百分数。
- **看分布形状，不只看均值**：均值容易被极值拉动，中位数 + 25/75 分位 + 直方图一起看。均值正、中位数为 0 通常意味着"少数暴涨撑着"，这种信号难以稳定复现。
- **看事件后的路径**：`max_up` / `max_down` 说明事件后窗口内的波动幅度，直接关系到能不能扛住回撤。
- **别跨量纲做事件定义**（见 `pitfalls.md`）。

## 实测对照（同样是"布林下轨"事件，量纲不同结果完全不同）

条件 A：`CROSSDOWN(EMA(CLOSE,3), MA(CLOSE,30)-2*STD(CLOSE,30))`（3 日 EMA 下穿 30 日布林下轨），300 只随机股票、3183 个事件：

```text
后  1 日: 涨 54.7%  跌 43.1%  均值 +0.21%  中位 +0.31%
后  3 日: 涨 56.2%  跌 42.4%  均值 +0.78%  中位 +0.72%
后  5 日: 涨 58.3%  跌 40.6%  均值 +1.38%  中位 +1.20%
后 10 日: 涨 57.7%  跌 41.3%  均值 +1.98%  中位 +1.54%
```

条件 B：`CROSSDOWN(RSI(CLOSE,3), MA(CLOSE,30)-2*STD(CLOSE,30))`（把 EMA 换成 RSI，量纲从"元"变成 0~100），同样扫描：

```text
后  3 日: 涨 50.5%  跌 48.7%  均值 +0.20%  中位 +0.08%
后 10 日: 涨 48.9%  跌 50.8%  均值 +0.60%  中位 -0.20%
```

条件 A 有清晰的信息量（回踩下轨后反弹，5 日上涨概率 58.3%），条件 B 就是噪声。原因不是 RSI 不好，而是 **RSI（0~100）和布林下轨（约 20 元）比大小没有物理意义**，交叉点基本是随机的。

## HTTP 与脚本调用

```bash
curl -X POST http://127.0.0.1:8765/api/feature/extract \
  -H "Content-Type: application/json" \
  -d '{"condition":"CROSSDOWN(EMA(CLOSE,3),MA(CLOSE,30)-2*STD(CLOSE,30))",
       "before":5,"after":10,"sample":300,"periods":[1,3,5,10]}'
```

```bash
python scripts/qlab.py events "CROSSDOWN(EMA(CLOSE,3),MA(CLOSE,30)-2*STD(CLOSE,30))" --periods 1,3,5,10 --sample 300
```

返回里的 `key` 可用来导出完整 CSV（`GET /api/feature/csv?key=...`，浏览器可直接下载）；`panel` 超过 3000 行时只回传前 3000 行，完整数据在服务端缓存里。
