# Quant Lab 股票分析方法

本地工作台在 `C:\Users\35788\Desktop\量化工具`（可用环境变量 `QUANTLAB_HOME` 覆盖），行情库 `market.db` 存着 5000+ 只 A 股、千万根级别的**未复权**日线。库会随同步前移，**动手前先看 `GET /api/db/health`** 确认股票数、K 线数和最后交易日，别用记忆里的数字。服务通常跑在 `http://127.0.0.1:8765`，局域网地址看启动脚本窗口。

## 这套系统怎么分析股票

三层链路，按顺序走，别跳层：

1. **表达式层**——把想法写成指标表达式（`MA(HIGH,3)`、`HIGH-LOW`、`RSI(CLOSE,14)`），既能画线看，也是后两层的基本输入。引擎有两份等价实现：服务端 `expr.py`、前端 `static/whiteboard.js`。
2. **回测层**——把表达式包成条件（上穿 / 下穿 / 区间极值 / 连续涨跌 / 等于某值 …），组装成买入与卖出规则，多条件用「且 / 或」折叠，单条可带仓位与延迟，在历史日线上模拟成交。引擎 `bt.py`。
3. **统计层**——先别急着回测，先问「这个事件出现之后通常怎么走」：找出所有事件 K 线，统计后续 1/2/3/5/10 日的涨跌概率与分位。引擎 `feature.py`。

推荐顺序是**先统计、再回测**：统计回答"信号有没有信息量"，回测回答"这份信息量扣掉成本和约束后还剩多少"。

## 动手前先定住三条口径

- **量纲要可比**。价格类指标（收盘、均线、布林轨，单位元）之间才能直接比大小或交叉；RSI 是 0~100 的无量纲值，跟价格比没有意义。实测对比：`RSI(CLOSE,3)` 下穿布林下轨 → 事件后 3 日上涨概率 50.5%（纯噪声）；换成 `EMA(CLOSE,3)` 下穿布林下轨 → 56.2%（有信息量）。跨量纲必须先把两边换算成同量纲，比如都取「距均线的百分比」。
- **样本要够、要可比**。统计先看 `n`，`n < 30` 的结论不要当结论；全市场扫描默认剔除 ST（涨跌幅限制不同，退市风险也不同）。
- **两个引擎要一致**。改 `expr.py` 的语义必须同步改 `whiteboard.js` 并做逐元素比对（历史上做过 70 条表达式比对、0 差异）。只改一边，页面看到的和回测算出来的就会对不上。

## 典型流程

1. **先把口语条件翻译成表达式并在真实行情上验证**，不要猜：

   ```bash
   python scripts/qlab.py expr "CROSS(MA(CLOSE,30)-2*STD(CLOSE,30), EMA(CLOSE,3))" --code 000001 --tail 5
   ```

2. **拿不准有没有信息量就先跑事件统计**：

   ```bash
   python scripts/qlab.py events "<条件表达式>" --periods 1,2,3,5,10 --sample 300
   ```

3. **再回测**（走 HTTP，见 `references/data-access.md`），设置区间、手续费、仓位、延迟，把收益 / 回撤 / 胜率 / 持仓时日均收益率与同期买入持有基准对比。

4. **下结论时必须带上**：样本数、时间区间、口径（未复权、费用、成交时点），以及 `references/pitfalls.md` 里的坑是否影响这次结论。
